意思の記録

本人の意思や回答を記録し、家族や医療関係者などへ共有するためのアプリです。いま入っているのは、担当機能を追加するための開発用の土台です。

起動確認

/health を開くと、アプリの応答とデータベース接続の結果が JSON で返ります。正常なら status と database はどちらも ok です。

データベース接続の初期値は、ローカル確認用の SQLite です。本番のデータベースは未決定です。

担当機能の入口

  • 回答

    入力・保存・閲覧。ブラウザ側の暗号化も含みます。未実装

    テスト用の回答画面

  • 共有

    共有の有効・無効、期限、QRコード。未実装

  • 認証

    パスキーの登録、ログイン、鍵の解除。

  • 家族共有

    招待、接続、選択した項目だけの共有。

  • 端末移行

    照合コードと新しいパスキーの確認後に、古いパスキーを無効化します。

決まっている方針

  • 運営サーバーに回答の内容を読ませない。
  • 回答の更新を共有先へ自動反映しない。本人が明示的に最新の意思を共有する。
  • 実在の個人情報や回答は、開発中のデータに使わない。
