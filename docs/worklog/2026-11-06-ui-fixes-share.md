# 2026-11-06 作業記録：共有画面を家族画面と同じ手順にそろえる

ブランチ: `feature/ui-fixes-share`（`main` の `2d90e88` から作成。PR #16 の内容を含む）

## 背景

家族画面（`/family`、`/family/share`）は、一覧の画面と、共有を作る手順の画面に分け、本人確認は回答を開くときに求める形にした（2026-10-30 の記録を参照）。共有画面（`/sharing`、共有リンク・QR）は、一覧とフォームが1画面にあり、上部の解除ボタンが必要だった。これを家族画面と同じ手順・同じ操作にそろえる。

## 対応

- `/sharing`（一覧）：`sharing/index.html`、`sharing.mjs`
  - 右上に「共有を開始」（`/sharing/new` へ進む）。作るフォームと「回答の暗号化を解除」のボタンを外した。
  - 「発行済みの共有」のカード（「一覧を更新」つき）。共有内容のモーダルは、「共有停止」（赤）と「閉じる」を右上に並べ、下部のボタンを無くした。
  - 暗号化された回答（発行済みの共有の中身）を開くときに、その場でパスキーの本人確認を求める（`qr-share-dialog.mjs`）。取り消したときは内容を出さず、「パスキーで本人確認して表示」で続けられる。一度済ませれば、同じ画面では再び求めない。
- `/sharing/new`（新規：`sharing/new.html`、`sharing-new.mjs`、`sharing-flow.mjs`、ルート `sharing.new`）
  - 手順：①ロック解除 → ②共有内容の選択 → ③リンクの種類と期限 → ④再確認 →（確定）。見出しは「ロックを解除してください。」「共有範囲を選択してください。」「どんなリンクを、いつまで有効にしますか？」「この内容で共有リンクを作りますか？」。
  - 家族に共有する画面と同じ操作：手順の表示から終わった手順へ戻れる／開くと自動でロック解除を始め、解除したら共有範囲へ進む／範囲は未選択から／「次へ」は右寄せ、「戻る」は左／「共有画面へ戻る」は右上（戻る矢印つき）／押せない理由の表示／本人確認が切れたら最初に戻る／アカウントが変わったら止める。
  - 共有リンクに固有の部分は、これまでどおり：緊急用（初期値）・期限付き（31日以内、期限は必須）・長期（最長3年、既定は3年後、強い注意書き）。確認した内容（回答・種類・期限）だけを共有し、確認のあとに種類や期限が変わったら作らず「リンクの種類と期限」へ戻す。作成後は、QR・リンク・コピー・「共有リンクを開く」を、同じ画面の最後の手順に出す。
  - 期限の判定・選べる範囲・確認の鍵（`longExpiryDefault`、`expiryBounds`、`qrConfirmationKey`）は `sharing-flow.mjs` に移した（中身は変えていない）。
- 変更：`base.html`（メニューの「共有」を `/sharing/new` でも現在地にする）、`answers/demo.html`（「共有リンクを作る」の行き先を `/sharing/new` に）、`tests/e2e/family_edge.js`（QR 閲覧の場面で共有リンクを作る手順を、新しい画面に合わせた）、説明（`README.md`、`docs/answer-demo.md`、`docs/morishita.md`）。

## 全ページ共通：エラー表示を、ページ本文の枠の上の枠に出す

### 対応

- 共通レイアウト（`base.html`）に、ページ本文の枠（`#site-content`）の上のエラー表示の枠（`#site-alert`、赤、閉じるボタンつき、`role="alert"`）を追加した。本文の枠と同じ縦の並び（`.site-column`）に置き、普段は隠す。狭い画面でも同じ並び。メニューのドロワーを開いている間は、本文と同じく操作できなくする（`menu.mjs`）。
- 共通の部品 `app/static/js/watashi/site-alert.mjs`：
  - `notify(root, 表示欄, 文言, エラーか)`：エラーは上の枠に出してページ内の表示欄を空にする。エラーでない文言は、ページ内の表示欄に出して前のエラー表示を消す。上の枠がないページ（`/auth`）では、エラーもページ内の表示欄に出す。
  - どこにも拾われなかった失敗（`unhandledrejection`・`error`）は、「予期しないエラーが起きました。」と上の枠に出す（内部の文言は見せない。通信の中断は出さない）。
- 各ページの表示を、`notify` に切り替えた（エラーの呼び出しにエラーの印を付けた）：共有（`sharing.mjs`）、共有リンクを作る（`sharing-new.mjs`）、家族（`family.mjs`）、家族に共有する（`family-share.mjs`）、家族の招待・確認（`family-invitation.mjs`、`family-confirm.mjs`）、移行（`transfer.mjs`）、QR閲覧（`view.mjs`）、アカウント（`account.mjs`）、回答のテスト画面（`answer-demo-page.mjs`）。
- 変えていないもの：`/auth`（ログイン・新規登録）は共通レイアウトを持たないので、これまでどおり画面内に出す。モーダルの中の表示欄（共有内容など）は、その中の文脈なのでそのまま。回答の入力欄の検証メッセージ（`answer-demo.mjs`）。
- 変更：`base.html`、`style.css`、`site-alert.mjs`（新規）、`menu.mjs`、上の各 `.mjs`、`docs/morishita.md`（使い方）。
